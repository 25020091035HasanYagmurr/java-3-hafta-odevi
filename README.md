# Java Exercises Collection

Bu klasör, kullanıcı tarafından verilen alıştırma sorularının her birini ayrı proje olarak içerir.

Projeler:
- Q1 - MyInteger
- Q2 - MyPoint
- Q3 - Course
- Q4 - Queue
- Q5 - Prime Factors
- Q6 - Prime Numbers
- Q7 - Circle2D
- Q8 - Approximate e

Her proje kendi `src` klasörü içindedir ve `Main.java` ile test edilir.
